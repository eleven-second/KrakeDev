git clone: <Clona un repositorio, creando una copia exacta en la maquina loca>
git commit:<Guarda una version de los cambios realizados en la maquina local, que anteriormente preparamos con git add.>
git push: <Sube los cambios locales realizados al repositorio remoto, después de usar git add y git commit>
git status: <Muestra el estado actual del repositorio local, detallando archivos nuevos, modificados o pendientes por preparar>
git add: <Eliges qué archivos quieres guardar. Es como meter cosas en una caja antes de cerrarla (git commit) >
